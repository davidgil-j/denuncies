| URL /canal/:slug -> PublicApp guard | `:slug` is attacker-controllable URL input; resolved via the SECURITY DEFINER RPC (parameterized), returns at most one org or null — no enumeration beyond brute-forcing exact slugs (slugs are non-secret shareable links per ADMIN-02) |
| PublicApp guard -> ComplaintForm/TrackingPortal organizationId prop | org.id is freshly re-resolved per route via useEffect keyed on [slug]; never read from cached form state (Pitfall 1) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-09 | Tampering / Elevation of Privilege | organizationId threaded from stale/cached state into a complaint insert under the wrong org | mitigate | org is resolved in a `useEffect` keyed on `[slug]` and passed as `org.id` directly; a slug change re-resolves; organizationId never derives from form state (Pitfall 1, acceptance criteria assert `organizationId={org.id}`) |
| T-03-10 | Information Disclosure | slug enumeration to discover organization names via /canal/<guess> | accept | get_organization_by_slug returns only id/name/slug for an exact match and nothing for a miss; slugs are intentionally public shareable links (ADMIN-02) — no additional mitigation needed (RESEARCH.md Security Domain) |
| T-03-11 | Denial of Service | unbounded slug-resolution requests on every keystroke/navigation | accept | Resolution runs once per route mount (useEffect keyed on [slug]), not per keystroke; the RPC is a single indexed lookup — negligible load, consistent with existing AdminGuard pattern |
| T-03-05 | Tampering | SQL injection via slug | accept | slug passed as parameterized `p_slug` rpc() arg in the supabase.js wrapper, never concatenated (ASVS V5) |
